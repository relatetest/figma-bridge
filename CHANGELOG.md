# Changelog

Изменения по релизам плагина `figma-bridge`. Новые записи пишутся в `Unreleased`; при релизе раздел получает номер версии и дату, а его текст уходит в GitHub Release и в поле «Что нового» формы публикации.

## Unreleased

## 0.2.0 — 2026-11-13

- Установка одной командой для всех: `npx -y github:relatetest/figma-bridge`. Ставит мост, скилл для Claude Code (`~/.claude/skills`) и для Codex, Cursor и других агентов (`~/.agents/skills`), правило в общие инструкции агентов. `--project .` добавляет правило в проект, `--no-rule` пропускает общие инструкции.
- В README раздел «Для агента» и готовая фраза: человек отдаёт её своему агенту, тот ставит всё сам.
- Флаг установщика `--skills`.

## 0.1.0 — 2026-11-13

Первая версия в Relate. Собрана из студийного моста relate→←figma (раньше Claude Bridge).

- Скилл `relate-figma-bridge`: агент работает в открытом файле Figma через плагин relate→←figma, когда официальный Figma MCP недоступен или когда просят мост.
- Установщик ставит мост в постоянную папку `~/.relate/figma-bridge` (macOS и Windows), обновляет его и по флагам `--project` и `--global` прописывает правило в `AGENTS.md` и `CLAUDE.md`.
- Окно плагина само узнаёт путь к серверу на этом компьютере, кнопка копирует верную команду запуска.
